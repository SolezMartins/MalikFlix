# MalikFlix v1.2.1

Personal-use Expo Android app for browsing and watching legally available Internet Archive movie sources.

This build intentionally uses a minimal Expo dependency set to make cloud Android builds more reliable.

## Build with Codemagic
1. Push the project to GitHub.
2. In Codemagic, choose the `malikflix-android` workflow.
3. Start a build.
4. Download `app-debug.apk` from Artifacts.
